# 手表小宠

一只住在手表表盘里的桌面小宠。表盘上的四道圆环就是它的饱食、心情、精力、清洁，点按钮照顾它，它会长大、升级、说话。

## 样子

- 深色玻璃表盘：流动的极光色块、闪烁星点、玻璃反光与底部暗角，天色会随它的状态变化——状态差时暗淡，睡觉时转成冷蓝。
- 四道圆环用渐变色描边，各带同色辉光，数值一掉就缩短。
- 小宠有地面投影、肚皮高光、随机眨眼、摇尾巴、眨眼发亮的小皇冠；睡觉时闭眼冒 Zzz，饿了会变成苦脸。
- 数值是一整块玻璃面板分四格；按钮是带彩色光圈的大圆角卡片，按下有回弹；底部是等级与经验条。
- 每次照顾都有触感反馈：喂食是咀嚼的三下轻点，玩耍是弹跳，洗澡是泡泡连续破裂，睡觉是一段很轻的持续震动（在 App 里播放，普通浏览器没有）。

## 运行

纯静态页面，没有构建步骤：直接用浏览器打开 `index.html` 即可。

整页按 Apple Watch 45mm 的 **396 × 484** 点阵排版（`index.html` 里的 `.device`），再整体等比缩放：

- 在手机上打开，就是一块手表的等比例预览，屏幕越大显示越大；
- 在手表上的网页预览窗口打开，缩放比接近 1，界面刚好铺满屏幕。

## 玩法

- **喂食**：饱食 +26，心情 +4，但会弄脏一点点。
- **玩耍**：心情 +22，代价是精力 -14、饱食 -8；精力低于 12 时会闹脾气。
- **洗澡**：清洁 +34，心情 +6。
- **睡觉**：精力持续回升，睡到满会自动醒来；精力耗尽也会自己睡着。
- **摸头**：点一下小宠，心情 +3。

四项数值会随时间自然下降，关掉页面也照样流逝（离线最多结算 8 小时），每次照顾都会积累经验，满了就升级换称号：小豆 → 圆豆 → 豆丁 → 豆仔 → 豆哥 → 豆侠 → 豆仙。

进度存在 `localStorage`（键名 `watchpet.v1`），换设备或清缓存会重新养一只。

## 分享

仓库地址：<https://github.com/441423095-dotcom/watch-pet>

### 网页托管

**现在就能发出去的地址**（不需要任何设置）：

<https://raw.githack.com/441423095-dotcom/watch-pet/main/index.html>

**永久地址**（等托管开好之后）：<https://441423095-dotcom.github.io/watch-pet/>

仓库里带了 `.github/workflows/pages.yml`，托管一开，以后每次推送到 `main` 都会自动更新。开启这一步只能在网页上点，App 里没有这个权限：

1. 打开 <https://github.com/441423095-dotcom/watch-pet/settings/pages>
2. **Source** 选 `GitHub Actions`，点 **Save**
3. 之后 Actions 会自己跑，绿色勾出现后永久地址就能打开了

### 发到 iMessage

1. 在 iPhone 的 Safari 里打开上面那个 `github.io` 网址，等小宠出现
2. 点底部的**分享**按钮（方框加向上箭头）
3. 选**信息**，挑联系人，发送

想当成 App 用，就在分享菜单里选「添加到主屏幕」。

### 在手表上玩

用信息把链接发给自己，在手表的「信息」里点开那条链接，watchOS 会用精简的网页预览窗口打开它。功能有限（存档不一定保留），但能看、能点。

## 文件

- `index.html`：表盘、小宠 SVG、数值与按钮的结构
- `style.css`：表壳、圆环、动画与配色
- `app.js`：数值结算、存档、互动台词与动画触发
